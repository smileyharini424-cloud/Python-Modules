# Python Modules

## Explanation

A module is a Python file containing functions, variables, or classes that can be reused in another Python program.

Modules help organize code and make programs easier to maintain and reuse.

## Problem Statement

Create a custom Python module containing arithmetic functions and import the module into another Python file to perform calculations.

## Features

* Creates a custom Python module
* Defines reusable functions
* Imports a custom module
* Performs arithmetic operations
* Demonstrates code reusability

## How It Works

The project contains two Python files:

* `calculator.py` contains arithmetic functions.
* `main.py` imports `calculator.py` and uses its functions.

## Technologies Used

* Python 3

## Program Flow

1. Create the `calculator.py` module.
2. Define arithmetic functions inside the module.
3. Create `main.py`.
4. Import the `calculator` module.
5. Read two numbers.
6. Call functions from the module.
7. Display the results.
8. End the program.

## Sample Input

```text id="w7c2pk"

```

## Sample Output

